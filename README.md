## 👨‍💻 Tentang Saya

```yaml
nama: "Arif Efendi"
role: "Mahasiswa D4 Teknik Elektronika"
kampus: "Universitas Negeri Yogyakarta"
fokus:
  - Embedded Systems
  - Robotika (Kinematika & Odometri)
  - Internet of Things (IoT)
  - Computer Vision
status: "Sedang membangun portofolio engineering berbasis solusi praktis 🔧"
```

Saya senang mengeksplorasi teknologi *embedded systems*, robotika, IoT, dan *computer vision*, mulai dari perancangan hardware, penulisan firmware, hingga integrasi sistem kendali secara menyeluruh. Saya rutin mendokumentasikan proyek, mengelola kode sumber di GitHub, dan mengembangkan lingkungan kerja berbasis Linux seperti ROS2 di Ubuntu untuk mendukung riset dan pengembangan robotika.

- 🔭 Sedang mengerjakan: **Robot Forklift Keypad** dengan odometri & *inverse kinematics*
- 🌱 Sedang mempelajari: **ROS2 Humble** dan integrasi *computer vision* untuk navigasi robot
- 🤝 Terbuka untuk kolaborasi: proyek IoT, robotika, dan sistem *embedded*
- 💬 Tanya saya soal: **ESP32, STM32, Arduino, Python, ROS2**
- ⚡ Fun fact: senang mengubah ide sederhana jadi prototipe yang benar-benar berjalan
